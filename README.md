
# Threat Modeling Dashboard

## Objective
Identify application security threats and prioritize defensive controls.

## Features
- System asset identification
- Likelihood and impact scoring
- Low, medium, and high risk classification
- Defensive security checklist

## Methodology
Threats can be organized using the STRIDE framework:
- Spoofing
- Tampering
- Repudiation
- Information Disclosure
- Denial of Service
- Elevation of Privilege

## Technologies
HTML, CSS, JavaScript

## Disclaimer
This project is an educational risk-assessment tool.
It does not perform penetration testing or automatically
detect vulnerabilities.
